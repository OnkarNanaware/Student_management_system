# 🎓 Student Task Management System

A sleek, responsive, and lightweight web application built with HTML5, CSS3, and JavaScript (ES6+). Designed to help students organize, manage, and track their academic tasks, assignments, and deadlines with ease.

---

## ✨ Features

- 📝 **CRUD Operations:** Create, Read, Update, and Delete academic tasks effortlessly.
- 🎯 **Priority Levels:** Assign priority tags (**Low**, **Medium**, **High**) with auto-styling.
- 📅 **Due Dates:** Keep track of assignment deadlines.
- 🔍 **Real-Time Search:** Instantly filter tasks by title.
- 🗂️ **Status Filtering:** View tasks by status (*All*, *Pending*, *Completed*).
- 💾 **Persistent Storage:** All data is saved automatically in browser `LocalStorage`.
- 📱 **Fully Responsive:** Optimized for desktops, tablets, and mobile devices.
- 🎨 **Modern UI:** Glassmorphism styling, clean typography, and interactive micro-animations.
- 🎨 **Modern analytics**
- 🎨 **Ai chatbot**
