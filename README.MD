Student Task Management System

A simple and user-friendly Student Task Management System built with HTML, CSS, and JavaScript. The application helps students organize, manage, and track their academic tasks efficiently.

Features
Add new tasks
Edit existing tasks
Delete completed or unwanted tasks
Mark tasks as completed
Search tasks by title
Filter tasks by status (All, Pending, Completed)
Set task priority
Add due dates
Store tasks using Local Storage
Responsive design for desktop and mobile devices
Technologies Used
HTML5
CSS3
JavaScript (ES6)
Browser Local Storage

Getting Started
Prerequisites

No additional software or installation is required.

Installation
Clone the repository.
git clone https://github.com/your-username/student-task-management-system.git

Navigate to the project folder.
cd student-task-management-system

Open index.html in your preferred web browser.
How to Use
Add a Task
Enter the task title.
Select the priority.
Choose a due date.
Click the Add Task button.
Edit a Task
Click the Edit button beside the task.
Update the required details.
Save the changes.
Complete a Task
Click the Complete button to mark a task as finished.
Delete a Task
Click the Delete button to permanently remove a task.
Search Tasks

Use the search bar to quickly find tasks by their title.

Filter Tasks

View:

All Tasks
Pending Tasks
Completed Tasks
Data Storage

All task data is stored locally in the browser using Local Storage. Your tasks remain available even after refreshing or reopening the browser.
